## Pruebas y límites

Las pruebas de API usan un MongoDB Memory Replica Set con transacciones. El recorrido integral crea una base `qa_mym_<id>` única, verifica cargos, cobros, asignaciones, asistencia y referencias, y detiene la réplica en `afterAll`. Los E2E usan una segunda réplica efímera, SMTP dirigido a `127.0.0.1:1` y Chromium. Las rutas de recordatorios siguen apagadas por defecto.

Los límites pendientes son operativos: ejecución del cron y valor de `CRON_SECRET` tras desplegar, aceptación de SMTP con destinatario autorizado, y cámara/altavoces de la tablet real. El cron local no prueba ejecución en Vercel. La política de primera mensualidad parcial `ASK` requiere una decisión administrativa y se registra como pendiente, no como cargo inventado.
