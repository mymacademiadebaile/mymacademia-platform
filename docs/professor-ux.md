# UX Profesor

La pantalla del profesor no debe sentirse como un backoffice.

## Criterios

- Diseñada primero para 360–480 px.
- Navegación inferior persistente.
- Una tarea principal por pantalla.
- Botones con área táctil grande.
- Resumen de la próxima clase en el inicio.
- Accesos rápidos a alumnos, clases, mensajes y promociones.
- Formularios cortos y progresivos.
- Estados y alertas expresados en lenguaje natural.
- Desktop conserva la experiencia compacta en un contenedor tipo dispositivo en vez de expandir tablas innecesariamente.

## Navegación inicial

Inicio · Clases · Alumnos · Perfil

Las promociones y mensajes aparecen como acciones contextuales, no como módulos administrativos separados.
